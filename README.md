# 🛒 电商用户消费行为分析

基于 Python 数据分析栈，对电商平台用户历史交易数据进行清洗、特征工程与 RFM 用户分层分析，旨在挖掘高价值用户群体并输出运营策略建议。

## 1.📂 项目结构

```markdown
ecommerce-user-consumption-analysis/
├── data/               # 原始数据与清洗后数据（已加入 .gitignore）
├── notebooks/          # 探索性分析 (EDA) 与可视化验证
├── src/                # 核心业务逻辑模块
│   ├── data_loader.py      # 数据加载与解析
│   ├── data_processor.py     # 数据清洗与异常值处理

```

## 3.📊 分析结论

本项目通过对电商用户消费行为的深度挖掘，得出以下核心结论：

### 3.1.数据集特征分析

- 日期格式需要进行转换
- 存在一个用户当天购买多笔订单的情况

---

### 3.2.数据集describe分析

- 用户购买数量均值 2.4 且标准差 2.3，有较小偏移但正常（波动较小）
- 50%分位在 2 但75分位数在 3，说明绝大多数订单购买量是不多的，最大数量为99，说明有大客户
- 用户购买金额中通过分位数可以看出大部分订单集中在 30 - 40 之间

---

### 3.3.每月产品销售数量，消费金额，次数，消费人数分析（按月份）

- 通过**每月产品购买数量**看出前三个月销量非常高，而后下滑但稳定，有下降趋势
- 通过**每月用户消费金额**看出前三个月消费金额也是很高，与消费数量同正比关系，三月后开始出现下滑，有下降趋势，判断是否跟月份有关
- 通过**每月订单量**可以看出前三个月订单量在9000-11000+左右，后续下滑到2500-3000+左右
- 通过**消费人数**可以看出前三个月的消费人数在8000-10000左右，后续平均2000左右的情况

**总结：前三个月用户消费情况飙高，后续恢复正常/常态化**

### 3.4.用户个体消费分析

- **用户角度：**共计23570个用户，均购买商品数量为7，但50中位数只有3，最大购买量为1033，均值大于中位数（右态分布）
- **消费金额：**均值消费106，中位数消费43，最高消费13990，均数与75位数相等，说明后面25%消费金额远高于均值（右态分布）
- 购买量与消费金额：呈线性趋势，每个商品单价在15左右（600/40），极值点较少（消费金额 > 1000 或购买量 > 60）对于样本数据来说影响较小，可忽略不计

---

### 3.5.用户消费分布分析

- 消费金额在 100 以内的订单占据大多数
- 用户购买数量非常小，集中在 50 以内，结合第一条可知：主用户是消费金额低，且购买购买数量 < 50 以内
- 前 20000 名用户贡献占比 40%，剩余用户占比 60% （2/8分布）
